# Chapter 06 - Operators

Complete coverage of JavaScript operators including assignment, arithmetic, modulus, exponentiation, compound, comparison (strict vs loose), logical, string concatenation, ternary, typeof, and increment/decrement operators.

## Files

| File | Description |
|------|-------------|
| `01_Assignment.js` | Assignment operators (`=`, `+=`, `-=`, etc.) |
| `02_Arithmatic.js` | Arithmetic operators (`+`, `-`, `*`, `/`) |
| `03_Modulus_OP.js` | Modulus operator (`%`) and remainder calculations |
| `04_exponentiation_OP.js` | Exponentiation operator (`**`) |
| `05_Compound_OP.js` | Compound assignment operators |
| `06_Comparison_OP.js` | Comparison operators (`>`, `<`, `>=`, `<=`) |
| `07_comparison_Strict_loose.js` | Strict (`===`) vs loose (`==`) equality |
| `08_IQ_loose_Strict.js` | Interview questions on loose vs strict comparison |
| `09_confusing_comaprisons.js` | Tricky comparison scenarios |
| `10_logical_OP.js` | Logical operators (`&&`, `||`, `!`) |
| `11_string_con_OP.js` | String concatenation operator |
| `12_null.js` | Null behavior with operators |
| `13.ternary_OP.js` | Ternary (conditional) operator |
| `14_typeof_OP.js` | typeof operator for type checking |
| `15_increment_decrement_OP.js` | Increment (`++`) and decrement (`--`) operators |
