# Chapter 09 - User Input

Handling user input in Node.js using readline, prompt-sync, and other input methods.

## Files

| File | Description |
|------|-------------|
| `01_userinput.js` | Introduction to user input in Node.js |
| `02_nodeReadline.js` | Using Node.js built-in readline module |
| `03_prompt_sync.js` | Using prompt-sync for synchronous input |

## How to Run

```bash
node 01_userinput.js
node 02_nodeReadline.js
node 03_prompt_sync.js
```

> Note: Some files may require installing additional packages like `prompt-sync` via `npm install prompt-sync`.
