# Chapter 04 - JavaScript Basis

Deep dive into variables (`var`, `let`, `const`), functions, hoisting behavior, block scope, and the temporal dead zone (TDZ).

## Files

| File | Description |
|------|-------------|
| `01_variable.js` | Variable declaration and usage |
| `02_functions.js` | Function declaration and invocation |
| `03_let.js` | The `let` keyword and block scoping |
| `04_const.js` | The `const` keyword and immutability |
| `05_Hoisting.js` | Hoisting behavior with `var` |
| `06_Hoisting_fn.js` | Function hoisting examples |
| `07_let_hoisting.js` | `let` hoisting and temporal dead zone |
| `08_let_hosting_block.js` | Block scope and TDZ demonstration |
| `09_let_const.js` | Comparison between `let` and `const` |
| `10_jr_QA.js` | QA-focused JavaScript interview questions |

## How to Run

```bash
node 01_variable.js
node 02_functions.js
node 03_let.js
node 04_const.js
node 05_Hoisting.js
node 06_Hoisting_fn.js
node 07_let_hoisting.js
node 08_let_hosting_block.js
node 09_let_const.js
node 10_jr_QA.js
```
